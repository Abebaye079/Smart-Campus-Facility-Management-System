# Smart Campus Facility Management System

## Description

A mobile application designed to manage and optimize the usage of campus facilities such as classrooms, laboratories, and equipment.
Users can create, view, update, and cancel reservations, while administrators manage facility availability and control access permissions.
The system includes authentication and role-based authorization and uses a RESTful API backend.
